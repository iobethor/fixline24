# FIXLINE 24 — сайт сервисной службы

Node.js + Express + EJS. Страницы рендерятся на сервере. Весь контент хранится в папке `data/`.

## Запуск

```
npm install
npm start        # http://localhost:3000
```

## Replit

Импортируйте репозиторий из Git. Файл `.replit` уже настроен: команда запуска `npm start`, порт 3000, есть конфиг деплоя.
Чтобы заявки с форм приходили в Telegram, добавьте в Secrets `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
Без них заявки сохраняются только в `data/leads.jsonl`. На деплое Replit этот файл не сохраняется между перезапусками, поэтому Telegram лучше подключить.

## Админ-панель

Вход: долгое нажатие (1,5 секунды) на логотип FIXLINE 24 в шапке сайта или адрес `/admin/`.

Пароль задаётся переменной окружения `ADMIN_PASSWORD`. На Replit: Tools → Secrets → `ADMIN_PASSWORD`. Без неё вход закрыт.
Необязательно: `SESSION_SECRET` — случайная строка для подписи входа. Если не задана, вычисляется из пароля, и при смене пароля все сессии сбрасываются.

В админке редактируется весь контент: общие настройки (название, логотип, контакты, счётчики, видео), главная, услуги, каталог, портфолио, статьи и тексты страниц. Там же:
- загрузка картинок: JPG/PNG автоматически сжимаются в WEBP;
- история: 15 последних версий каждого раздела, откат в один клик;
- заявки с форм сайта;
- загруженные файлы.

## Фирменный стиль

Палитра и шрифт заданы в `public/css/style.css` (блок `:root`): графит `#141A1A`, изумруд `#00B852`, неоново-зелёный `#2CF274`, тёплое золото `#C88C24`, мягкое золото `#FFD978`, слоновая кость `#FBFCFB`. Шрифт — Inter.

Логотип меняется в админке («Общие настройки» → «Логотип»). Быстро посмотреть варианты можно по адресам `?logo=gold` и `?logo=green` — это только просмотр, ничего не сохраняется.

Фотографии услуг подбираются под тёмно-зелёную гамму и приводятся к общему виду скриптом `tools/photo.js` (лёгкая коррекция, без перекраски).

## Где хранятся правки

На Render (у бесплатного тарифа нет постоянного диска) правки, загруженные файлы и заявки сохраняются в отдельный приватный репозиторий `iobethor/fixline24-data`, в нём есть телефоны клиентов, поэтому не делайте его публичным. На Render для этого заданы `GITHUB_TOKEN` (права Contents: read/write на этот репозиторий), `GITHUB_REPO=iobethor/fixline24-data` и `GITHUB_STORAGE_BRANCH=main`.

- `content/*.json` — исходный контент, лежит в git.
- Правки из админки, загруженные файлы и заявки на Replit хранятся в Replit Database. Они переживают перезапуск и передеплой. Локально всё это лежит в папке `storage/`, она в git не попадает.
- Кнопка «Сбросить раздел к исходной версии» в истории возвращает раздел к `content/*.json`.
- Ограничения Replit Database: до 5 МБ на один раздел или файл, до 50 МБ всего. Поэтому видео в админке ограничено 3,5 МБ. Большой ролик лучше положить в `public/video/` через git.
